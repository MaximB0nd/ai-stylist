# Контракт проверки фотографии формы генерации

Автор записи: Валаева Ирина Владимировна. Зона: frontend, страница генерации.

## Требование и ответственность

Для каждого из двух полей пользователь выбирает одну фотографию JPG, PNG или WebP размером от 1 до 10 МиБ включительно. Цепочка: ограничение формы генерации → проверка выбранных файлов → `photoSelectionError(files)` → `resolvePhotoSelection(files, validate)` → обработчик выбора фотографии в `mountGeneration`.

Модуль определяет допустимость набора файлов по метаданным `type` и `size`. Он не открывает изображение, не проверяет его содержимое и не отправляет данные на сервер. Декодирование и показ превью остаются обязанностью страницы; сервер обязан выполнять собственную проверку.

## Публичные операции

`photoSelectionError(files)` принимает массив или подобную массиву коллекцию файлов с `length` и элементами, имеющими `type` и `size`. Возвращает пустую строку для отсутствия выбора или допустимого одного файла; иначе возвращает сообщение для пользователя. Порядок проверок: количество файлов более одного → MIME-тип → размер более 10 × 1024 × 1024 байт → нулевой размер. Для пустого набора ошибка откладывается до отправки формы.

`resolvePhotoSelection(files, validate = photoSelectionError)` принимает ту же коллекцию и реализацию контракта проверки. Возвращает `{file, error}`: при ошибке или пустом выборе `file === null`, при допустимом выборе — тот же объект `files[0]`. Потребитель вызывает эту операцию до создания URL и декодирования. `mountGeneration(form, {photoSelectionError})` получает реализацию в точке сборки; обычный запуск использует `photoSelectionError`, тест может передать другую реализацию.

Вход не изменяется. Результат содержит ссылку на исходный файл и новую строку; файл остаётся во владении вызывающей стороны. Операции не хранят состояние и не выполняют ввод-вывод. Если передать не соответствующую контракту коллекцию или если переданная реализация выбросит исключение, исключение передаётся вызывающему коду. Модуль не обещает проверку реального содержимого файла по заголовку.

## Подмена и проверка

Тестовая реализация `fixedPhotoSelectionError` находится в `src/frontend/tests/generation_module_contract.test.js`. Она повторяет заявленные решения для фиксированных сценариев. Один и тот же `resolvePhotoSelection` вызывается с рабочей и тестовой реализацией без изменения кода потребителя. Тестовая подмена подтверждает решения на заданных метаданных, но не работу браузерного декодирования, загрузки или серверной проверки.

Команда из `src/frontend`: `node --test tests/generation_module_contract.test.js tests/generation_lab_validation.test.js tests/generation_validation.test.js`.
