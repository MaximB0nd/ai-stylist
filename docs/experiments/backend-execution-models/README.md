- `results.json` — исходные серии наблюдения от 24.11.2026, использованные в отчёте.

## Запуск

Из корня проекта в Git Bash при подготовленном Python 3.12 и зависимостях backend_core:

```bash
./.venv/Scripts/python.exe -u src/backend_core/labs/execution_models/experiment.py
```

Изолированная `.venv` подготавливается по обычной инструкции проекта.
Скрипт использует зависимости `src/backend_core/requirements.txt`.
Службы PostgreSQL, MinIO и AI Core для эксперимента не требуются.
HTTP-сервер слушает только `127.0.0.1` на автоматически выбранном порту.

Новый прогон записывает `src/backend_core/labs/execution_models/local-results.json`.
Этот файл исключён из Git. Историческая серия в `docs` сохраняется отдельно.
Для сравнения результатов требуется то же оборудование и протокол.

## Проверки корректности

При каждом прогоне нормализованные PNG сравниваются побайтно. Последовательная
и конкурентная загрузка проверяют статус и содержимое всех 24 ответов.
Для сводки проверяется число фотографий по каждому из восьми альбомов.
У `AlbumService` сравнивается полный DTO. Дополнительно проверяются ошибки
403 и 404, альбом без исходников и исключение при подписи.
Проверки используют `assert`, поэтому запускаются без флага `-O`.

Время сравнения результатов CPU вынесено за измеряемый интервал.
Начальные два раунда прогревают пулы, затем сохраняются пять повторов.
Время старта процессов не входит в CPU-серию.

## Область выводов

CPU-обработка использует настоящую `normalize_png`. В I/O-опыте сервер задаёт
задержку 20 мс. Тестовый поставщик подписи задаёт задержку 10 мс на ключ.
Репозиторий альбома возвращает данные из памяти. Результаты не являются
измерением рабочего MinIO или PostgreSQL.

Пауза `sleep(0)` в сводке расширяет окно потери обновления. Время сравнивается
между корректными вариантами, причём пауза сохранена и внутри блокировки.
Полученная разность не измеряет стоимость одного захвата `asyncio.Lock`.

`BoundedAlbumService` — экспериментальный подкласс. Он ограничивает подпись
четырьмя одновременными операциями, сохраняет проверку владельца и порядок
результатов. Штатный маршрут приложения продолжает использовать `AlbumService`.
