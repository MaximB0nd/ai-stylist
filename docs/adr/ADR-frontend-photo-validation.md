# ADR Проверка фотографии как заменяемое правило формы генерации

Автор: Валаева Ирина Владимировна. Дата: 16.10.2026. Статус: принято для frontend.

## Контекст

Форма генерации принимает два изображения. Перед декодированием и показом превью ей нужно проверить количество, MIME-тип и размер выбранных файлов. Эти правила должны быть проверяемы без браузерной загрузки изображений. Серверная проверка остаётся отдельной границей.

## Варианты

1. Держать все проверки внутри обработчика DOM-события. Меньше операций, но правило нельзя отдельно вызвать и подменить.
2. Выделить чистую публичную проверку `photoSelectionError` и потребителя `resolvePhotoSelection`; передавать реализацию правила в `mountGeneration`. Добавляются контракт и параметр, зато одинаковый потребитель принимает рабочую и тестовую реализации.

## Решение

Выбран вариант 2. Сначала проверяется количество файлов, затем MIME-тип, верхняя и нижняя границы размера. Пустой набор не считается ошибкой до отправки анкеты. Страница создаёт object URL только если `resolvePhotoSelection` вернул файл. Тестовая реализация подключается через параметр без изменения потребителя.

## Последствия и цена

Появляются дополнительная публичная операция и косвенный вызов функции проверки. Копирования содержимого файла нет. Возвращаемый объект сохраняет ссылку на переданный файл; владеет им вызывающая сторона. Проверка по MIME-метаданным не доказывает тип фактических байтов, а тестовая подмена не проверяет декодирование браузером и сервер. В текущем интерфейсе действие генерации отключено до интеграции сервиса.

## Способ проверки и будущий вопрос

Для обеих реализаций выполнить одинаковые сценарии: допустимый файл, ровно 10 МиБ, превышение на один байт, пустой файл, неподдерживаемый тип, два файла. Сверить, что потребитель не менялся. При будущей интеграции отдельно исследовать, как браузерная проверка и серверная проверка расходятся для файлов с неверным MIME или испорченными байтами.

Направления системной сложности для этой зоны: обработка данных (валидация метаданных и границ размера) и модель исполнения (асинхронное декодирование, повторный выбор и отмена устаревшего результата). Модуль-кандидат для отдельного исследования — обработка выбранного фото в `mountGeneration`: воспроизводимый вход — последовательность выбора файлов с заданными метаданными; наблюдаемые результаты — ошибка, состояние превью и освобождение object URL. До измерений узкое место не утверждается.
