# ADR-001: Инструментальный контур страницы генерации

Автор: Валаева Ирина Владимировна. Статус: принято для практической работы № 1.

## Контекст

AI Stylist — веб-приложение для подбора образов. Моя зона ответственности — frontend, прежде всего страница генерации. Для практической работы нужен компонент, который запускается без backend и AI Core, имеет проверяемый результат, конфигурацию, версию и диагностику. Реальная отправка анкеты и генерация образов зависят от последующей интеграции сервисов и здесь не утверждаются как проверенные.

## Решение

Используется существующий стек frontend: Python 3.14, Caspian/FastAPI для выдачи страницы, HTML/CSS и JavaScript для интерфейса. Отдельный `generation_lab.py` импортирует страницу и проверяет её наблюдаемый контракт без сети. Модель исполнения проверки последовательная: загрузка модулей Python, чтение конфигурации, построение HTML, анализ элементов и ресурсов, запись результата, завершение процесса. При обычном запуске приложения сервер обрабатывает HTTP-запросы событийно.

## Причины и альтернатива

Проверка использует существующие исходные файлы страницы и закреплённые зависимости `uv.lock`, поэтому результат связан с реальным frontend. Рассмотрена проверка через полноценную генерацию образов, но она требует backend и AI Core, а значит скрывает причины ошибок запуска frontend и не является минимальным автономным компонентом.

## Последствия

Результат проверки говорит о структуре формы и наличии локальных ресурсов. Он не доказывает успешную загрузку пользовательских фото, работу API, качество образов или удобство интерфейса. Для проверки этих свойств нужны отдельные интеграционные и пользовательские испытания.
