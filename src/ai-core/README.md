# Интеграция с AI Core

AI Core принимает две фотографии человека и предпочтения, асинхронно создаёт
запрошенное число изображений и предоставляет их для сохранения вашим backend.
Интеграция не зависит от языка, фреймворка, базы данных или хранилища backend.

- [Подключение и полный сценарий](docs/public/ai-core-api/README.md)
- [HTTP-контракт: запросы, ответы и состояния](docs/public/ai-core-api/CONTRACT.md)
- [Ошибки и действия клиента](docs/public/ai-core-api/ERRORS.md)
- [Примеры запросов и фотографий](examples/README.md)

Документация описывает внешний интерфейс v1 по состоянию на 19 октября 2026 года.
Адрес подключения и доступные ограничения уточняйте для используемого окружения;
актуальные возможности возвращает `GET /v1/capabilities`.
