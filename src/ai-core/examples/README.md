# Примеры для интеграции

Все люди на фотографиях вымышлены. Фотографии содержат намеренные недостатки
и не гарантируют успешного результата.

| Набор | Возраст | Пол | Особенности |
| --- | --- | --- | --- |
| `set-01` | 27 | female | слабый свет, небольшой смаз, бытовой фон |
| `set-02` | 41 | male | контровой свет, тени, блики на очках, сжатие |
| `set-03` | 58 | female | пересвет, сжатие, камера сверху |

Каждый набор содержит `face.png`, `full-body.png` и `input.json` с полным телом
`POST /v1/jobs`. Рост и предпочтения — иллюстративные значения.
Разместите файлы по согласованному HTTP origin, замените URL и `expires_at`
на действительные. Локальные пути к файлам в API не передаются.

- [Обычный запрос](set-01/input.json) подходит, когда drape_test необязателен.
- [Запрос с полным drape_test](request-with-drape.json) показывает 12 сравнений.
  ID/SHA-256 и результаты сравнений иллюстративны: замените их каталогом из capabilities
  и реальными ответами человека. Не используйте вымышленные ответы как данные пользователя.
