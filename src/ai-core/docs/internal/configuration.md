# Настройки AI Core

Этот файл — единственный реестр переменных окружения. Секретные значения не
хранятся в Git и не выводятся в журналы.

## Общие

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_SERVICE_NAME` | обязательно | Имя службы |
| `AI_CORE_ENVIRONMENT` | `local` | Окружение |
| `AI_CORE_LOG_LEVEL` | `INFO` | Уровень журналов |
| `AI_CORE_RABBITMQ_URL` | обязательно для внутренних служб | Подключение к RabbitMQ |
| `AI_CORE_RABBITMQ_PREFETCH` | `1` | Число одновременно полученных сообщений |
| `AI_CORE_ENVELOPE_SCHEMA_VERSION` | `1.0` | Версия общей оболочки сообщения |

## Внешний интерфейс AI Core

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_INTERNAL_TOKEN` | обязательно | Токен основного сервера |
| `AI_CORE_ORCHESTRATOR_URL` | обязательно | Адрес главного оркестратора |
| `AI_CORE_REQUEST_TIMEOUT_SECONDS` | `10` | Срок внутреннего запроса |
| `AI_CORE_MIN_IMAGE_COUNT` | `1` | Минимальное количество результатов |
| `AI_CORE_MAX_IMAGE_COUNT` | `10` | Максимальное количество результатов |

## Главный оркестратор

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_DATABASE_URL` | обязательно | Подключение к его PostgreSQL |
| `AI_CORE_OUTBOX_INTERVAL_MS` | `250` | Частота публикации `outbox` |
| `AI_CORE_WORKER_ATTEMPT_TIMEOUT_SECONDS` | `600` | Базовый срок команды воркеру |
| `AI_CORE_INPUT_QUEUE_BUDGET_SECONDS` | `600` | Допустимое ожидание подготовки в очереди |
| `AI_CORE_JOB_TIMEOUT_SECONDS` | `3600` | Общий срок выполнения задания |
| `AI_CORE_RESULT_DOWNLOAD_TTL_SECONDS` | `86400` | Срок получения готовых временных результатов |
| `AI_CORE_MAX_ATTEMPTS_PER_IMAGE` | `3` | Максимум модельных попыток результата |
| `AI_CORE_MAX_ACTIVE_JOBS` | `100` | Максимум активных заданий |
| `AI_CORE_ARTIFACT_SERVICE_URL` | обязательно | Адрес службы временных файлов |
| `AI_CORE_ARTIFACT_SERVICE_TOKEN` | обязательно, секрет | Токен внутреннего вызова службы временных файлов |

## Служба доступа к временным файлам

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_ARTIFACT_SERVICE_TOKEN` | обязательно, секрет | Токен разрешённых внутренних клиентов |
| `AI_CORE_TEMP_STORAGE_ENDPOINT` | обязательно | Адрес S3-совместимого временного хранилища |
| `AI_CORE_TEMP_STORAGE_BUCKET` | обязательно | Корзина временных файлов AI Core |
| `AI_CORE_TEMP_STORAGE_REGION` | обязательно | Регион временного хранилища |
| `AI_CORE_TEMP_STORAGE_ACCESS_KEY` | обязательно, секрет | Ключ доступа только к временной корзине |
| `AI_CORE_TEMP_STORAGE_SECRET_KEY` | обязательно, секрет | Секрет только временной корзины |
| `AI_CORE_ARTIFACT_URL_TTL_SECONDS` | `900` | Срок короткой ссылки чтения или записи |
| `AI_CORE_ARTIFACT_TTL_SECONDS` | `90000` | Предельный срок жизни временного объекта |
| `AI_CORE_ARTIFACT_MAX_SIZE_BYTES` | `15728640` | Максимальный размер одного изображения |

## Воркер

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_WORKER_TYPE` | обязательно | Вид воркера из реестра сообщений |
| `AI_CORE_WORKER_COMMAND_QUEUE` | обязательно | Его очередь команд |
| `AI_CORE_WORKER_RESULT_QUEUE` | обязательно | Его очередь результатов |
| `AI_CORE_WORKER_CONCURRENCY` | `1` | Параллельные команды копии |

Воркеру очистки дополнительно требуются `AI_CORE_ARTIFACT_SERVICE_URL` и
`AI_CORE_ARTIFACT_SERVICE_TOKEN`. Ключи S3 не передаются ни одному воркеру.

## Воркер модели

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_MODEL_NAME` | обязательно | Имя модели |
| `AI_CORE_MODEL_VERSION` | обязательно | Точная версия модели |
| `AI_CORE_MODEL_TIMEOUT_SECONDS` | `600` | Срок вызова модели |

## Воркер уведомлений

| Переменная | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_STATUS_CALLBACK_URL` | обязательно | Доверенный адрес основного сервера |
| `AI_CORE_STATUS_CALLBACK_SECRET` | обязательно | Секрет подписи |
| `AI_CORE_STATUS_CALLBACK_TIMEOUT_SECONDS` | `10` | Срок отправки |
| `AI_CORE_STATUS_CALLBACK_MAX_ATTEMPTS` | `10` | Максимум попыток доставки |

Локальный `.env` допустим, но не добавляется в Git. В репозитории может храниться
только `.env.example` без значений секретов.
