# Блок проверки результата

Блок оценивает кандидата и возвращает одно из решений: `ACCEPTED`, `REJECTED` или
`INCONCLUSIVE`. Он не запускает новую генерацию самостоятельно.

- [Воркер проверки](worker/README.md)

Набор обязательных проверок находится в
[общем документе моделей](../../models.md#проверка-результата).
