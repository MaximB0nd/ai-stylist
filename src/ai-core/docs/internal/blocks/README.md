# Блоки микросервисов

Блок группирует документацию одного вида воркеров. Он не является отдельной
управляющей службой и не имеет своей базы. Общие правила не копируются в блоки и
находятся в [родительской документации](../README.md).

| Блок | Результат блока |
| --- | --- |
| [Управление](orchestration/README.md) | Следующий этап или конечное состояние задания |
| [Временные файлы](artifacts/README.md) | Ограниченные ссылки и удаление временных файлов AI Core |
| [Подготовка](preparation/README.md) | Проверенные нормализованные входные изображения |
| [Стилист](styling/README.md) | Проверенные кандидаты `OutfitSpec` |
| [Генерация](generation/README.md) | Один кандидат изображения |
| [Проверка](verification/README.md) | Решение о качестве кандидата |
| [Очистка](cleanup/README.md) | Итог удаления переданных временных файлов |
| [Уведомления](notification/README.md) | Итог доставки события основному серверу |
