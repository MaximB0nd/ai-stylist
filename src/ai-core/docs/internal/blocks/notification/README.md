# Блок уведомлений

Блок доставляет неизменяемое событие состояния основному серверу и возвращает
итог доставки. Он не вычисляет состояние задания.

- [Воркер уведомлений](worker/README.md)

Формат внешнего уведомления находится только в
[публичном договоре](../../../public/ai-core-api/CONTRACT.md#уведомление-о-состоянии).
