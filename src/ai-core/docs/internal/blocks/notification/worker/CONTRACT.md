# Договор воркера уведомлений

Имена очередей и оболочка сообщения определены в
[реестре сообщений](../../../messaging.md#очереди-воркеров). Формат события и
подписи определяется только в
[публичном договоре](../../../../public/ai-core-api/CONTRACT.md#уведомление-о-состоянии).

Команда содержит поле `event` с неизменяемым публичным событием. Адрес и секрет
не передаются в сообщении и берутся из настроек службы.

Результат содержит `status`, `event_id` из публичного события, HTTP-код и время
доставки в UTC.

Любой `2xx` означает доставку. Сетевые ошибки, `429` и `5xx` временные; остальные
`4xx` окончательные. Для `429` и `503` соблюдается `Retry-After`. Для остальных
временных ошибок задержка удваивается от одной секунды до пяти минут и получает
случайное смещение от нуля до вычисленной задержки. После исчерпания числа
попыток воркер возвращает `DELIVERY_EXHAUSTED`; оркестратор сохраняет окончательный
итог для ручного безопасного повтора того же `event_id`.
