# Воркер очистки

Служба вызывает переданные ссылки удаления и возвращает итог главному
оркестратору. Она не выбирает файлы, не получает постоянных прав и не работает с
альбомами или постоянными результатами.

- Эксплуатация: [../../../operations.md](../../../operations.md)
