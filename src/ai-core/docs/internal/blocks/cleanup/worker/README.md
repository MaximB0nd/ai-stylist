# Воркер очистки

Служба получает список `artifact_id`, вызывает службу временных файлов и
возвращает итог главному оркестратору. Она не выбирает файлы, не получает ключи
S3 и не работает с альбомами или постоянными результатами.

- Эксплуатация: [../../../operations.md](../../../operations.md)
