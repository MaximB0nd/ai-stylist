# Служба доступа к временным файлам

Служба выдаёт короткие ссылки на чтение и запись объектов временного хранилища
AI Core и выполняет удаление по `artifact_id`. Она не передаёт байты через
главный оркестратор и не знает о постоянном хранилище продукта.
