# Блок управления конвейером

Блок связывает публичную службу API с внутренними блоками и является владельцем
общего хода задания.

Служба блока:

- [главный оркестратор](main-orchestrator/README.md).

Внутренняя операция для службы API и договор запуска воркеров находятся в
[договоре главного оркестратора](main-orchestrator/CONTRACT.md).
