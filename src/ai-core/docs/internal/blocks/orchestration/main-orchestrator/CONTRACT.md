# Договор главного оркестратора

## Операции для внешнего интерфейса AI Core

Внешний интерфейс AI Core вызывает главный оркестратор по HTTP во внутренней сети. Все запросы
имеют `Content-Type: application/json` и `Authorization: Bearer <internal-token>`.
Токен и базовый адрес находятся в
[реестре настроек](../../../configuration.md#внешний-интерфейс-ai-core).

| Метод и путь | Вход | Результат |
| --- | --- | --- |
| `POST /internal/v1/jobs` | `idempotency_key_hash` и проверенный объект запроса из [публичного договора](../../../../public/ai-core-api/CONTRACT.md#создание-задания) | `201` и публичный ответ создания; повтор — `200` с тем же ответом |
| `GET /internal/v1/jobs/{job_id}` | Параметр пути | `200` и публичное представление задания |
| `POST /internal/v1/jobs/{job_id}/cancel` | Пустой объект | `200` и публичное представление задания |
| `POST /internal/v1/jobs/{job_id}/results/ack` | Пустой объект | `204` |

`idempotency_key_hash` — SHA-256 исходного ключа, записанный шестнадцатеричной
строкой. Исходный ключ не передаётся и не хранится. Повтор каждой операции
безопасен. Внутренний ответ ошибки имеет поля `code`, `message` и `retryable`;
внешний интерфейс AI Core преобразует его в безопасную ошибку из публичного договора.

`400` означает нарушение внутреннего договора, `401` — неверный токен, `404` —
неизвестное задание, `409` — конфликт ключа или состояния, `503` — временную
неготовность. Срок запроса берётся из
[единого реестра настроек](../../../configuration.md#внешний-интерфейс-ai-core); после тайм-аута
внешний интерфейс AI Core безопасно повторяет тот же запрос.

## Договор с воркерами

Главный оркестратор публикует команды каждому виду воркеров и принимает их
результаты. Имена очередей, оболочка и правила повторной доставки находятся
только в [реестре сообщений](../../../messaging.md#очереди-воркеров). Полезная
нагрузка принадлежит договору соответствующего воркера.

Перед командой, создающей временный файл, оркестратор создаёт `artifact_id`,
записывает его состояние и получает ограниченную ссылку у
[службы временных файлов](../../artifacts/access-service/CONTRACT.md). Повтор для
того же назначения и места результата обновляет ссылку, не создавая новый файл.

Конечные состояния и условие завершения определены только в
[публичном договоре](../../../../public/ai-core-api/CONTRACT.md#завершённое-задание).
