# Модели и проверяемые структуры

Этот файл — единственный источник решений по моделям, `OutfitSpec` и проверке
изображений. Пороговые значения выбираются по
[результатам сравнения](model-benchmark.md), а не считаются заданными заранее.

## AI-стилист

Начальный кандидат — Qwen3.5-4B. Qwen3.5-9B рассматривается, если меньшая модель
не соблюдает ограничения или даёт однообразные комплекты.

Стилист состоит из трёх частей:

1. программные правила проверяют обязательные категории, таксономию и запреты;
2. языковая модель создаёт варианты;
3. валидатор отклоняет неверную структуру, противоречия и повторы.

Службы блока: [blocks/styling/README.md](blocks/styling/README.md).

## `OutfitSpec` версии 1

`OutfitSpec` — единственный внутренний формат комплекта между стилистом,
генерацией и проверкой. Структура проверяется по
[схеме JSON](schemas/outfit-spec-v1.schema.json), значения одежды — по
[единому справочнику](taxonomies/outfit-v1.json). `occasion` и `style` используют
значения из [публичного договора](../public/ai-core-api/CONTRACT.md#допустимые-предпочтения).

```json
{
  "schema_version": "1.0",
  "outfit_id": "f883f0d6-61bf-432d-9bed-074d912db2f0",
  "occasion": "office",
  "style": "classic",
  "items": [
    {
      "category": "outerwear",
      "type": "jacket",
      "color": "navy",
      "material": "wool"
    },
    {
      "category": "bottom",
      "type": "trousers",
      "color": "gray",
      "material": "wool"
    },
    {
      "category": "shoes",
      "type": "loafers",
      "color": "black",
      "material": "leather"
    }
  ],
  "constraints": {
    "full_body": true,
    "standing_pose": true
  },
  "explanation": "Сдержанный комплект для офиса"
}
```

Обязательные поля и допустимость пустых значений определяет только схема.
Несовместимое изменение создаёт новую старшую версию.

`material` всегда обязателен; для неизвестного материала используется только
значение `unknown` из справочника. Для хеша из объекта удаляются `outfit_id` и `explanation`, элементы `items`
сортируются по `category`, `type`, `color`, `material`, затем объект кодируется
как канонический JSON по RFC 8785 в UTF-8. SHA-256 этих байтов в нижнем регистре
резервируется главным оркестратором до генерации.

## Генерация изображения

Кандидаты для измерений:

- FLUX.2-klein-4B — компактная начальная модель;
- Qwen-Image-Edit-2511 — более требовательный кандидат для сложного
  редактирования по нескольким изображениям.

Выбор определяется качеством лица и телосложения, соответствием `OutfitSpec`,
анатомией, временем, видеопамятью и стоимостью. Службы блока:
[blocks/generation/README.md](blocks/generation/README.md).

## Проверка результата

Обязательные проверки:

1. сходство лица;
2. сохранение телосложения;
3. наличие человека в полный рост;
4. соответствие `OutfitSpec`;
5. анатомические и визуальные дефекты;
6. безопасность;
7. отличие от уже принятых результатов задания.

Итог — `ACCEPTED`, `REJECTED` или `INCONCLUSIVE`. Отсутствующая обязательная
проверка не может дать `ACCEPTED`. Службы блока:
[blocks/verification/README.md](blocks/verification/README.md).

## Развёртывание моделей

Каждая модель находится внутри воркера своего блока. Отдельный сервер модели не
является скрытой службой без собственного договора. Воркеры одного типа
масштабируются одинаковыми копиями. Если модель не помещается на одном GPU, одна
копия воркера может владеть неделимой группой GPU; для увеличения пропускной
способности добавляются новые копии группы.
