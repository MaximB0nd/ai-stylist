# Модели и структуры

## Кандидаты

| Этап | Начальный кандидат | Запасной кандидат |
| --- | --- | --- |
| Стилист | Qwen3.5-4B | Qwen3.5-9B |
| Генерация | FLUX.2-klein-4B | Qwen-Image-Edit-2511 |

Выбор: [model-benchmark.md](model-benchmark.md).

## Стилист

1. Проверка входных ограничений.
2. Вызов языковой модели.
3. Проверка схемы, противоречий и повторов.

Договор: [services/styling-worker/CONTRACT.md](services/styling-worker/CONTRACT.md).

## `OutfitSpec` версии 1

| Правило | Источник |
| --- | --- |
| Структура | [schema-v1.json](contracts/outfit/schema-v1.json) |
| `occasion`, `style` | [внешний договор](../public/ai-core-api/CONTRACT.md#допустимые-предпочтения) |

- Несовместимое изменение требует новой старшей версии.

Хеш комплекта:

1. Удалить `outfit_id` и `explanation`.
2. Отсортировать `items` по `category`, `type`, `color`, `material`.
3. Кодировать по RFC 8785, UTF-8.
4. Вычислить SHA-256 в нижнем регистре.
5. Зарезервировать хеш до генерации.

## Проверка изображения

- сходство лица;
- телосложение;
- полный рост;
- соответствие `OutfitSpec`;
- анатомия и визуальные дефекты;
- безопасность;
- отличие от принятых результатов задания.

Решение: `ACCEPTED`, `REJECTED`, `INCONCLUSIVE`.

Отсутствующая обязательная проверка запрещает `ACCEPTED`.

## Развёртывание

- Модель работает внутри своей службы-воркера.
- Отдельный сервер модели требует отдельного договора.
- Один воркер может владеть группой GPU.
- Масштабирование — новые одинаковые копии воркера.
