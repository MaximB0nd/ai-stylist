# Политика данных

## Данные

| Данные | Правило |
| --- | --- |
| `user_id` | Не передаётся в AI Core |
| Приведённый запрос | Хранится в PostgreSQL до завершения задания |
| Ссылки и свободный текст | Шифруются при хранении |
| Изображения | Хранятся только во временном S3 AI Core |
| Ключи временного S3 | Только у службы временных файлов |
| Постоянные файлы и альбомы | Вне AI Core |

## Запрещено журналировать

- изображения;
- ссылки;
- токены и ключи;
- полный пользовательский текст.

## Удаление

- Ошибка или отмена: главный оркестратор удаляет известные временные файлы через службу временных файлов.
- `ACKNOWLEDGED`: главный оркестратор удаляет временные результаты.
- `EXPIRED`: главный оркестратор удаляет временные результаты.
- Правило жизненного цикла временного S3 удаляет только пропущенные просроченные объекты.
- Поздний результат отменённой или просроченной попытки не принимается.
