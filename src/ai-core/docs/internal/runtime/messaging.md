# Сообщения RabbitMQ

## Назначение

- Главный оркестратор передаёт команды воркерам.
- Воркеры возвращают результат главному оркестратору.
- Воркеры не вызывают друг друга.
- Файлы через RabbitMQ не передаются.

## Общие поля

Каждое сообщение содержит:

- уникальный идентификатор сообщения;
- идентификатор задания;
- тип сообщения;
- версию договора;
- данные команды или результата.

Точный формат определяется вместе с первой реализацией воркера.

## Доставка

- Сообщение может быть доставлено повторно.
- Повторная доставка не должна повторять уже применённое действие.
- Воркер подтверждает команду после публикации результата.
- Оркестратор подтверждает результат после сохранения изменения состояния.
- Решение о новом запуске принимает только главный оркестратор.
- Названия очередей и правила ошибок определяются при реализации соответствующего воркера.
