# Состояние AI Core

## Владелец

- Главный оркестратор хранит состояние задания, текущий этап и принятые результаты.
- PostgreSQL хранит состояние главного оркестратора.
- Воркеры не читают PostgreSQL и не хранят состояние задания.
- RabbitMQ передаёт сообщения, но не является источником состояния.

## Состояния задания

| Состояние | Значение |
| --- | --- |
| `QUEUED` | Задание принято и ожидает обработки |
| `PROCESSING` | Выполняется хотя бы один этап |
| `COMPLETED` | Получено запрошенное число результатов |
| `FAILED` | Задание завершено ошибкой |
| `CANCELLED` | Задание отменено |

## Правила

- Состояние меняет только главный оркестратор.
- Повторное сообщение не должно повторно менять состояние.
- После отмены новые этапы не запускаются, поздние результаты не принимаются.
- После перезапуска оркестратор продолжает только незавершённую работу.
- Структура таблиц определяется при реализации главного оркестратора.
