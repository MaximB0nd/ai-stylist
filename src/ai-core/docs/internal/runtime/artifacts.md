# Временные файлы

## Ответственность

| Объект | Владелец |
| --- | --- |
| Временное хранилище и его ключи | Служба временных файлов |
| Сведения о файлах задания | Главный оркестратор |
| Постоянное хранение результатов | Основной сервер |

- Только служба временных файлов обращается к временному S3.
- Воркеры и основной сервер работают через короткие ссылки.
- AI Core не обращается к постоянному хранилищу продукта.
- Байты файлов не проходят через главный оркестратор и RabbitMQ.

## Жизненный цикл

1. Главный оркестратор создаёт идентификатор временного файла.
2. Служба временных файлов выдаёт ссылку на чтение или запись.
3. Воркер читает или записывает файл по ссылке.
4. Основной сервер скачивает принятый результат.
5. После подтверждения, ошибки, отмены или окончания срока файл удаляется.

Повторное удаление безопасно. Точный формат идентификаторов, ссылок и сроки определяются при реализации службы.
