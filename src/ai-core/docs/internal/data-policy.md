# Политика данных AI Core

Этот файл — единственный источник правил работы AI Core с чувствительными и
временными данными.

## Входные данные

- AI Core получает только необходимые поля профиля и ограниченные по времени
  ссылки из публичного запроса.
- Идентификатор пользователя не передаётся.
- Ссылки, изображения, токены и полный пользовательский текст не записываются в
  журналы и технические показатели.

## Временные данные

- Воркер получает в команде готовые ограниченные по времени ссылки только на те
  файлы, которые нужны этой попытке.
- Временный результат имеет отдельный адрес для каждого `worker_run_id`, номера
  результата и попытки. Поздний воркер не может перезаписать новый результат.
- AI Core не выдаёт файловые права и не хранит постоянные ключи доступа. Для
  очистки главный оркестратор передаёт воркеру готовые одноразовые ссылки
  удаления только временных файлов.

## Постоянные данные

AI Core не владеет пользователями, альбомами, сроками хранения и удалением
файлов. Устройство файлового модуля находится за границей нашей документации.

## Удаление и отмена

После ошибки или отмены главный оркестратор создаёт команды очистки известных
временных файлов. После завершения он делает это, когда основной сервер выполнит
[подтверждение получения](../public/CONTRACT.md#подтверждение-получения-результатов)
либо истечёт опубликованный срок доступности результатов.
Поздний результат отменённой попытки не возвращается в рабочий процесс. Сроки и
удаление постоянных файлов остаются вне AI Core.
