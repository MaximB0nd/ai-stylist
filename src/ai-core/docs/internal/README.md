## Блоки микросервисов

Состав и границы блоков перечислены в [blocks/README.md](blocks/README.md).

Общие внутренние правила:

- главный оркестратор напрямую отправляет команды воркерам через общий RabbitMQ;
- воркеры не вызывают друг друга и не читают базы оркестраторов;
- каждая служба разворачивается независимо;
- общий ход задания и все попытки принадлежат главному оркестратору.
