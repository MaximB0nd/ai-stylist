# Эксплуатация

## Поля журнала

`service_name`, `job_id`, `worker_run_id`, `message_id`, `attempt`.

Ограничения: [data-policy.md](data-policy.md#запрещено-журналировать).

## Показатели

| Группа | Показатели |
| --- | --- |
| Задания | количество по состояниям, полное время |
| Этапы | время, попытки, причины ошибок |
| Очереди | глубина, возраст, повторы, окончательные ошибки |
| Модели | процессор, память, GPU, видеопамять |
| Файлы | объём, количество, возраст, ошибки ссылок, очередь удаления |
| Результаты | отклонения, ошибки SHA-256 |
| Уведомления | задержка, число попыток, итог доставки |

## Готовность

| Служба | Проверка |
| --- | --- |
| Все службы | обязательные настройки и соединения |
| Оркестратор | PostgreSQL, RabbitMQ, служба файлов |
| Воркер модели | модель и RabbitMQ |
| Служба файлов | временное S3 |

## Предупреждения

- рост возраста очереди;
- исчерпание повторов;
- недоступность модели;
- превышение срока задания;
- рост очереди удаления.

Пороги задаются после измерений.
