# Архитектура AI Core

## Результат

Ровно `requested_image_count` проверенных изображений без повторов комплектов.

## Схема

![Архитектура AI Core](images/ai-system-architecture.png)

## Компоненты

| Компонент | Ответственность |
| --- | --- |
| Внешний интерфейс | HTTP-договор с основным сервером |
| Главный оркестратор | Состояние, порядок этапов, попытки, конечный результат |
| PostgreSQL | Состояние оркестратора |
| RabbitMQ | Команды воркерам и результаты |
| Служба временных файлов | Единственный доступ к временному S3; поток, ссылки, удаление |
| Временное S3 | Входные копии, промежуточные файлы, результаты |
| Воркеры | Выполнение одной команды без выбора следующего этапа |
| Основной сервер | Постоянное хранение и подтверждение получения |

## Порядок этапов

```text
создание → подготовка → стилист → резерв комплекта → генерация → проверка
         → повтор или принятие → N результатов → скачивание → ACK → удаление файлов
```

## Инварианты

- Один владелец каждого вида состояния.
- Один главный оркестратор; в первой версии — одна копия.
- Один PostgreSQL оркестратора.
- Один RabbitMQ на окружение.
- Воркеры без собственных баз.
- Воркеры одного типа масштабируются одинаковыми копиями.
- Временное хранилище принадлежит AI Core.
- Постоянное хранилище находится вне AI Core.
- Передача файлов — только через службу временных файлов по коротким ссылкам.
- Новый этап требует очереди и договора воркера.
