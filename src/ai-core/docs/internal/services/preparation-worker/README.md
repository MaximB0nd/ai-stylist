# Воркер подготовки

## Для чего создан

Приводит исходные фотографии к безопасному и одинаковому формату перед вызовом
моделей.

## Функции

- читает фотографию лица и фотографию в полный рост по коротким ссылкам;
- проверяет формат, размер и читаемость файлов;
- отклоняет недопустимое или небезопасное содержимое;
- удаляет метаданные исходных файлов;
- нормализует формат, размеры и цветовое пространство;
- записывает подготовленные фотографии по выданным ссылкам;
- возвращает `artifact_id`, SHA-256, размер, формат, ширину и высоту каждого файла;
- возвращает код временной или окончательной ошибки.

## Не выполняет

- не выбирает одежду;
- не создаёт итоговое изображение;
- не хранит состояние задания;
- не выбирает следующий этап и не создаёт повторную попытку.
