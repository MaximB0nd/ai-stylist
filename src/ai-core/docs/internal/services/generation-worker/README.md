# Служба генерации

## Для чего создан

Создаёт одно изображение человека в заданном комплекте одежды.

## Функции

- читает подготовленные фотографии лица и тела по ссылкам;
- принимает структурированное описание комплекта и параметры запуска модели;
- запускает модель генерации с переданными параметрами;
- записывает изображение-кандидат по выданной ссылке;
- вычисляет SHA-256 и размер результата;
- возвращает формат, ширину, высоту и использованные версии;
- возвращает код временной или окончательной ошибки.

## Не выполняет

- не выбирает комплект одежды;
- не проверяет качество готового изображения;
- не принимает результат в итоговый набор;
- не хранит состояние задания и не запускает повторы.
- не знает о способе оркестрации или очередях.
