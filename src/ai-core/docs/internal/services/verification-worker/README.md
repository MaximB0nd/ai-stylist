# Воркер проверки

## Для чего создан

Оценивает изображение-кандидат до добавления в итоговый набор.

## Функции

- читает исходные фотографии и изображение-кандидат по коротким ссылкам;
- проверяет сходство лица;
- проверяет наличие человека в полный рост;
- проверяет соответствие заданному комплекту одежды;
- оценивает визуальное качество по заданной версии политики;
- возвращает `ACCEPTED`, `REJECTED` или `INCONCLUSIVE`;
- возвращает оценки и коды причин;
- возвращает код временной или окончательной ошибки.

## Не выполняет

- не изменяет изображение;
- не добавляет результат в итоговый набор;
- не создаёт новую попытку генерации;
- не хранит состояние задания.
