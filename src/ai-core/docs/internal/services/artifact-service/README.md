# Служба временных файлов

## Ответственность

Единственная служба AI Core с ключами доступа к временному S3.

| Функция | Результат |
| --- | --- |
| Проверка запроса | допустимые `artifact_id`, операция, формат и размер |
| Определение объекта | ключ S3 по `artifact_id` |
| Выдача доступа | короткая ссылка на одну операцию `READ` или `WRITE` |
| Передача данных | поток между клиентом ссылки и S3 |
| Удаление | безопасное повторное удаление по `artifact_id` |
| Проверка готовности | доступность настроек и временного S3 |

Короткая ссылка ведёт на службу. Служба передаёт байты потоком и не сохраняет их локально.

## Вызовы

| Участник | Действие |
| --- | --- |
| Главный оркестратор | запрашивает ссылки и удаляет разрешённые файлы |
| Воркеры | читают и пишут через полученные ссылки |
| Основной сервер | скачивает результат через полученную ссылку |

## Не отвечает

- не создаёт `artifact_id`;
- не хранит состояние заданий и файлов;
- не выбирает срок хранения;
- не запускает этапы и повторы;
- не проверяет содержимое изображений;
- не хранит файлы локально;
- не работает с постоянным хранилищем продукта.
