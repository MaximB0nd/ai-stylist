# Служба временных файлов

## Для чего создана

Изолирует временное S3 от остальных служб. Это единственная служба AI Core с
адресом и ключами доступа к временному хранилищу.

## Функции

- проверяет `artifact_id`, операцию, формат и допустимый размер;
- определяет ключ объекта по `artifact_id`;
- выдаёт короткую ссылку на одну операцию `READ` или `WRITE`;
- передаёт байты между клиентом ссылки и S3 без локального сохранения;
- удаляет объект по `artifact_id`;
- считает повторное удаление успешным;
- проверяет доступность настроек и временного S3.

## Вызовы

| Участник | Действие |
| --- | --- |
| Главный оркестратор | запрашивает ссылки и удаляет разрешённые файлы |
| Воркеры | читают и пишут через полученные ссылки |
| Основной сервер | скачивает результат через полученную ссылку |

## Не выполняет

- не создаёт `artifact_id`;
- не хранит состояние заданий и файлов;
- не выбирает срок хранения;
- не запускает этапы и повторы;
- не проверяет содержимое изображений;
- не хранит файлы локально;
- не работает с постоянным хранилищем продукта.
