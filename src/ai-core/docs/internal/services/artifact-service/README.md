# Служба временных файлов

## Для чего создана

Изолирует временное S3 от остальных служб и является artifact gateway для
фактической передачи байтов. Это единственная служба AI Core с адресом и ключами
доступа к временному хранилищу. Отдельная служба, которая только предварительно
проверяет ссылку, не используется: правила безопасности применяет компонент,
который сам читает или записывает поток.

## Функции

- проверяет `artifact_id`, операцию, формат, срок хранения и допустимый размер;
- определяет ключ объекта по `artifact_id`;
- по команде оркестратора импортирует входной файл только с разрешённого origin
  основного сервера;
- выдаёт HTTP-ссылку на операцию `READ` или `WRITE`;
- принимает передачу по ссылке на чтение или запись;
- передаёт байты между клиентом ссылки и S3 без локального сохранения;
- ограничивает поток по числу байтов независимо от `Content-Length`;
- сверяет сигнатуру формата и безопасно проверяет декодирование, размеры,
  количество пикселей и кадров, EXIF и ICC;
- публикует записанный объект для чтения только после технической проверки;
- удаляет объект по `artifact_id`;
- считает повторное удаление успешным;
- проверяет доступность настроек и временного S3.

## Вызовы

| Участник | Действие |
| --- | --- |
| Главный оркестратор | импортирует входы, запрашивает ссылки и удаляет разрешённые файлы |
| Processing services | читают и пишут через полученные ссылки |
| Основной сервер | скачивает результат через полученную ссылку |

## Не выполняет

- не создаёт `artifact_id`;
- не хранит состояние заданий и не имеет отдельной БД метаданных;
- не принимает произвольные внешние URL вне import endpoint и allowlist;
- не выбирает срок хранения;
- не запускает этапы и повторы;
- не проверяет предметную пригодность фотографии или результат ML-модели;
- не исправляет, не перекодирует и не нормализует изображение;
- не хранит файлы локально;
- не работает с постоянным хранилищем продукта.
