# Служба проверки лица

## Для чего создана

Определяет, подходит ли фотография лица для нормализации, проверки личности и
определения цветотипа.

## Функции

- читает одно изображение по короткой ссылке;
- проверяет наличие ровно одного основного лица;
- проверяет размер, положение и допустимый поворот лица;
- проверяет резкость, экспозицию и равномерность освещения;
- возвращает `ACCEPTED` или `REJECTED` со стабильными причинами;
- возвращает версию модели.

Начальный кандидат модели: `opencv/face_detection_yunet` с Hugging Face.
Пороговые значения определяются benchmark, а не договором службы.

## Не выполняет

- не исправляет освещение и не ретуширует кожу;
- не сравнивает личности;
- не удаляет фон и не определяет цветотип;
- не запускает другие службы и не планирует повтор.

## Договор

Endpoint: `POST /v1/validate`.

Точные поля и причины отклонения определяет [договор службы](CONTRACT.md).
Транспорт, авторизация и системные ошибки следуют
[общему договору](../../CONTRACT.md).
