# Служба проверки полного роста

## Для чего создана

Определяет, подходит ли фотография человека в полный рост для дальнейшей
нормализации и генерации.

## Функции

- читает одно изображение по ссылке;
- проверяет наличие ровно одного основного человека;
- проверяет видимость головы, корпуса, рук и ног;
- отклоняет критическое обрезание и перекрытие тела;
- проверяет минимальные разрешение и резкость;
- возвращает `ACCEPTED` или `REJECTED` со стабильными причинами;
- возвращает версии принадлежащих службе моделей.

Начальные кандидаты: `opencv/person_detection_mediapipe` и
`opencv/pose_estimation_mediapipe` с Hugging Face. Они образуют один небольшой
модельный bundle одного этапа и не используются другими службами.

## Не выполняет

- не сравнивает личности;
- не удаляет фон и не изменяет изображение;
- не запускает другие службы и не планирует повтор.

## Договор

Endpoint: `POST /v1/validate`.

Точные поля и причины отклонения определяет [договор службы](CONTRACT.md).
Транспорт и системные ошибки следуют
[общему договору](../../CONTRACT.md), а границы ответственности, безопасность и
повторы — [общему поведению processing services](../../README.md).
