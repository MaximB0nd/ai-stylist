# Служба проверки личности

## Для чего создана

Проверяет, что на фотографии лица и фотографии в полный рост изображён один
человек.

## Функции

- читает два изображения по коротким ссылкам;
- выделяет и выравнивает сравниваемые лица;
- сравнивает признаки лиц моделью распознавания;
- возвращает `SAME_PERSON` или `DIFFERENT_PERSON`;
- возвращает версию модели без similarity score во внешнем ответе службы.

Начальный кандидат модели: `opencv/face_recognition_sface` с Hugging Face.
Порог совпадения определяется на закрытом наборе.

## Не выполняет

- не хранит embedding и не идентифицирует человека по базе;
- не исправляет и не нормализует фотографии;
- не запускает другие службы и не планирует повтор.

## Договор

Endpoint: `POST /v1/compare`.

Точные поля, решения и причины отклонения определяет
