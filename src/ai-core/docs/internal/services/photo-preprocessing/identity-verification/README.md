# Служба проверки личности

## Для чего создана

Проверяет, что на фотографии лица и фотографии в полный рост изображён один
человек.

## Функции

- читает два изображения по коротким ссылкам;
- находит ровно одно сравнимое лицо на каждом изображении моделью detection;
- выравнивает лица по пяти landmarks;
- сравнивает признаки лиц моделью recognition;
- возвращает `SAME_PERSON` или `DIFFERENT_PERSON`;
- возвращает версии принадлежащих службе моделей без similarity score во
  внешнем ответе службы.

Начальные кандидаты: `opencv/face_detection_yunet` и
`opencv/face_recognition_sface` с Hugging Face. Они образуют один небольшой
model bundle внутри одной службы: YuNet возвращает лицо и пять landmarks, SFace
выравнивает лицо, строит embedding и сравнивает его. Служба не вызывает
face-validation и загружает собственные закреплённые revisions обеих моделей.
Пороги detection, минимального лица и совпадения определяются на закрытом наборе.

## Не выполняет

- не хранит embedding и не идентифицирует человека по базе;
- не исправляет и не нормализует фотографии;
- не принимает landmarks или embedding от другой службы;
- не запускает другие службы и не планирует повтор.
