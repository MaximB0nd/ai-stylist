# Служба определения цветотипа

## Для чего создана

Определяет один из четырёх сезонных цветотипов по уже проверенной и
нормализованной фотографии лица.

## Функции

- читает RGB sRGB PNG с белым фоном по короткой ссылке;
- применяет закреплённые вместе с моделью детерминированные tensor transforms;
- запускает закреплённую версию модели классификации;
- возвращает `spring`, `summer`, `autumn` или `winter`;
- применяет внутренний порог качества и при ненадёжном результате возвращает
  ошибку `422 COLOR_TYPE_UNCERTAIN`;
- возвращает версию модели.

Начальный benchmark-кандидат: EfficientNet-B0
`jiwoonkim00/personal-color-classifier` с Hugging Face. Его опубликованная схема
обучения использует face crop и skin masking и не совпадает автоматически с
выходом нашего normalizer. Поэтому кандидат допускается в production только если
показывает принятые per-class показатели на закрытом наборе, пропущенном через
реальный pipeline AI Core.

Предпочтительный production-вариант при непрохождении benchmark — один
компактный классификатор, дообученный на нормализованных изображениях AI Core и
опубликованный в Hugging Face. Он должен принимать контрактный PNG без
дополнительных detector или segmentation моделей во время inference. Resize,
crop и нормализация tensor не считаются отдельными моделями и версионируются
вместе с весами.

## Не выполняет

- не удаляет фон и не перезаписывает входной артефакт;
- не выполняет автоматический баланс белого или коррекцию цвета;
- не возвращает confidence модели;
- не угадывает цветотип при недостаточной уверенности;
- не запускает другие службы и не планирует повтор.
