# Служба определения цветотипа

## Для чего создана

Определяет один из четырёх сезонных цветотипов по уже проверенной и
нормализованной фотографии лица.

## Функции

- читает RGB sRGB PNG с белым фоном по короткой ссылке;
- запускает закреплённую версию модели классификации;
- возвращает `spring`, `summer`, `autumn` или `winter`;
- применяет внутренний порог качества и при ненадёжном результате возвращает
  `REJECTED` с причиной `COLOR_TYPE_UNCERTAIN`;
- возвращает версию модели.

Начальный кандидат: EfficientNet-B0 `jiwoonkim00/personal-color-classifier` с
Hugging Face. Он допускается к использованию только после benchmark на целевых
данных проекта.

## Не выполняет

- не удаляет фон и не изменяет изображение;
- не возвращает confidence модели;
- не угадывает цветотип при недостаточной уверенности;
- не запускает другие службы и не планирует повтор.

## Договор

Endpoint: `POST /v1/classify`.

Успешный ответ содержит только `request_id`, `color_type` и `model_version`.
Служба следует [общему договору](../../CONTRACT.md).
