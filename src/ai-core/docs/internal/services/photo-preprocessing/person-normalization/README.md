# Служба нормализации человека

## Для чего создана

Удаляет фон с одного изображения человека и приводит результат к каноническому
виду без изменения цвета кожи.

## Функции

- читает одно изображение по короткой ссылке;
- применяет EXIF orientation и корректно переводит ICC-профиль в sRGB;
- отделяет человека от фона моделью сегментации;
- размещает результат на фоне `#FFFFFF` без растягивания;
- изменяет размер и добавляет поля по параметрам вызова;
- удаляет метаданные и записывает RGB PNG по переданной ссылке;
- возвращает SHA-256, размер, ширину, высоту и версию модели.

Начальный кандидат модели: block-quantized
`opencv/human_segmentation_pphumanseg` с Hugging Face.

Для AI Core начальные профили: лицо `512 × 512`, полный рост `768 × 1024`.
Размеры являются настройками вызывающей стороны, а не назначением службы.

## Не выполняет

- не применяет автоматический баланс белого, коррекцию экспозиции, контраста или
  насыщенности;
- не ретуширует кожу;
- не определяет тип входной фотографии или цветотип;
- не запускает другие службы и не планирует повтор.

## Договор

Endpoint: `POST /v1/normalize`.

Точные поля, параметры результата и причины отклонения определяет
[договор службы](CONTRACT.md). Транспорт, авторизация и системные ошибки следуют
[общему договору](../../CONTRACT.md). Один вызов обрабатывает одно изображение.
Вызывающая сторона отдельно вызывает службу для лица и полного роста.
