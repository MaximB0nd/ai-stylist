# Главный оркестратор

## Для чего создан

Единственный владелец задания AI Core. Управляет полным процессом от принятия
запроса до готового набора результатов или конечной ошибки.

## Функции

- создаёт задание и сохраняет полный приведённый запрос;
- хранит состояние задания и каждого требуемого изображения;
- выбирает следующий этап обработки;
- создаёт `artifact_id` и запрашивает временный доступ к файлам;
- публикует команды воркерам и принимает их результаты;
- предотвращает повторное применение одного сообщения;
- управляет повторными запусками и отклоняет неактуальные результаты;
- резервирует неповторяющиеся комплекты внутри задания;
- принимает или отклоняет результаты проверки;
- обрабатывает отмену и конечные ошибки;
- формирует события изменения состояния;
- после подтверждения, ошибки, отмены или истечения срока удаляет временные файлы.

## Не выполняет

- не запускает модели;
- не обрабатывает изображения;
- не передаёт байты файлов;
- не хранит постоянные пользовательские файлы.
