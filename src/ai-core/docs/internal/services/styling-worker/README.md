# Воркер-стилист

## Для чего создан

Формирует структурированные варианты одежды по данным человека и его пожеланиям.

## Функции

- принимает профиль человека и пожелания к образу;
- учитывает список уже использованных комплектов;
- вызывает заданную версию языковой модели и инструкции;
- формирует структурированные варианты комплектов;
- проверяет каждый вариант по действующему договору;
- возвращает версии модели и инструкции;
- возвращает код временной или окончательной ошибки.

## Не выполняет

- не резервирует выбранный комплект;
- не решает, какой кандидат станет итоговым;
- не создаёт изображения;
- не хранит состояние задания и не запускает повторы.
