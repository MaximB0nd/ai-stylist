# Служба уведомлений

## Для чего создан

Доставляет основному серверу события об изменении состояния задания, не включая
HTTP-вызовы во внутреннюю логику оркестратора.

## Функции

- принимает неизменяемое событие состояния;
- формирует тело запроса по внешнему договору;
- добавляет время и подпись HMAC-SHA256;
- отправляет событие на доверенный адрес из настроек;
- считает любой ответ `2xx` успешной доставкой;
- различает временные и окончательные ошибки доставки;
- соблюдает `Retry-After` для `429` и `503`;
- возвращает `event_id`, HTTP-код и время доставки.

## Не выполняет

- не создаёт событие и не меняет его данные;
- не меняет состояние задания;
- не передаёт изображения;
- не выбирает следующий этап обработки.
- не знает о способе оркестрации или очередях.
