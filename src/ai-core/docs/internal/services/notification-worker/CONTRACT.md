# Договор воркера уведомлений

Оболочка и очереди: [messaging.md](../../messaging.md).

## Команда

| Поле | Значение |
| --- | --- |
| `event` | событие из [внешнего договора](../../../public/ai-core-api/CONTRACT.md#уведомление-о-состоянии) |

Адрес и секрет берутся из настроек.

## Результат

| Поле | Значение |
| --- | --- |
| `status` | общий статус воркера |
| `event_id` | идентификатор события |
| `http_status` | последний HTTP-код |
| `delivered_at` | UTC |

## Доставка

| Ответ | Итог |
| --- | --- |
| `2xx` | успех |
| сеть, `429`, `5xx` | временная ошибка |
| остальные `4xx` | окончательная ошибка |

- `Retry-After` соблюдается для `429` и `503`.
- Иная задержка: 1 секунда, удвоение до 5 минут, случайное смещение.
- После предела попыток: `DELIVERY_EXHAUSTED`.
- Ручной повтор использует тот же `event_id`.

Ошибка и отмена: [общий результат](../../messaging.md#результат-воркера).
