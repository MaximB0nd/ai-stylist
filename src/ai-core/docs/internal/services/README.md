# Службы AI Core

| Служба | Ответственность |
| --- | --- |
| [Главный оркестратор](main-orchestrator/README.md) | состояние задания и порядок этапов |
| [Служба временных файлов](artifact-service/README.md) | единственный доступ к временному S3 |
| [Предобработка фотографий](photo-preprocessing/README.md) | проверка и нормализация входных фотографий, цветотип |
| [Служба-стилист](styling-worker/README.md) | создание вариантов одежды |
| [Служба генерации](generation-worker/README.md) | создание изображения кандидата |
| [Служба проверки](verification-worker/README.md) | проверка изображения кандидата |
| [Служба уведомлений](notification-worker/README.md) | доставка события состояния |

Processing services следуют [общему HTTP-договору](CONTRACT.md). Они не знают о
главном оркестраторе или очередях. Порядок этапов и повторы находятся снаружи.
