# Настройки AI Core

## 1. Назначение

AI Core самостоятельно задаёт рабочие ограничения. Они не принадлежат основному
серверу и не должны быть зашиты в договор взаимодействия как неизменяемые числа.
Основной сервер может узнать допустимый диапазон из документации или отдельного
служебного запроса, но AI Core всегда повторно проверяет входные данные.

## 2. Настройки первой версии

| Переменная окружения | Начальное значение | Назначение |
| --- | ---: | --- |
| `AI_CORE_MIN_IMAGE_COUNT` | `1` | Минимальное количество изображений в задании |
| `AI_CORE_MAX_IMAGE_COUNT` | `10` | Максимальное количество изображений в задании |
| `AI_CORE_MAX_ATTEMPTS_PER_IMAGE` | `3` | Максимум попыток для одного места результата |
| `AI_CORE_JOB_LEASE_SECONDS` | `120` | Срок аренды задания исполнителем |
| `AI_CORE_JOB_HEARTBEAT_SECONDS` | `30` | Частота продления аренды |
| `AI_CORE_INPUT_URL_MIN_TTL_SECONDS` | `600` | Минимальный остаточный срок ссылки на исходник |
| `AI_CORE_TEMP_DATA_TTL_HOURS` | `24` | Срок хранения временных данных после завершения |
| `AI_CORE_STATUS_CALLBACK_URL` | нет | Доверенный адрес уведомлений основного сервера |
| `AI_CORE_STATUS_CALLBACK_TIMEOUT_SECONDS` | `10` | Ограничение времени одной отправки уведомления |
| `AI_CORE_INTERNAL_TOKEN` | нет | Служебный токен входящих запросов |
| `AI_CORE_STATUS_CALLBACK_SECRET` | нет | Секрет подписи исходящих уведомлений |

Начальные значения являются решением для первой версии и проверяются нагрузочными
и модельными испытаниями. Изменение диапазона количества изображений не требует
изменения формата запроса.

## 3. Правила

- Секреты не записываются в репозиторий, не приводятся в примерах значений и не
  выводятся в журналы.
- Адрес уведомлений задаётся оператором AI Core, а не пользователем запроса.
- Неверные или отсутствующие обязательные настройки останавливают запуск с понятной
  ошибкой.
- В журналах при запуске показываются только несекретные значения.
- Все исполнители одного окружения используют одинаковые ограничения.
- Файл `.env` может использоваться локально, но не добавляется в Git.
