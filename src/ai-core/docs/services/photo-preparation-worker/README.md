# Микросервис подготовки фотографий

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Этот микросервис загружает исходные фотографии по временным ссылкам, проверяет формат,
размер и читаемость, удаляет служебные метаданные, нормализует изображение и
сохраняет временную копию для следующих этапов.

## Входы и выходы

- Читает `ai.worker.photo.prepare.commands`.
- Возвращает ссылки на временные нормализованные объекты, размеры, формат и
  безопасные признаки изображения в `ai.worker.photo.prepare.results`.

## Владение данными

Не хранит состояние задания и не обращается к PostgreSQL. Команды получает только
от оркестратора своей группы. Временные объекты
создаёт только в выделенной области конкретного задания.

## Развёртывание и масштабирование

Каждая копия является отдельным микросервисом и может работать на любом хосте с
доступом к RabbitMQ и модулю хранения. Если подготовка использует модели зрения,
для таких копий выделяется соответствующий GPU.

## Сбои и безопасность

- Повтор одной команды перезаписывает тот же временный объект или возвращает уже
  подтверждённый результат.
- Неверный или опасный файл возвращает окончательную ошибку.
- Временные ссылки, изображения и извлечённые метаданные не записываются в журналы.

## Наблюдение

Измеряются время загрузки и обработки, размеры файлов, причины отклонения,
ошибки модуля хранения и число обработанных фотографий.
