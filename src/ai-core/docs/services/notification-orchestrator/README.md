# Оркестратор группы уведомлений

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Принимает сохранённое событие состояния, управляет попытками доставки и возвращает
главному оркестратору подтверждение или окончательный отказ.

## Владение и развёртывание

Хранит локальное состояние доставки и время следующей попытки в своей PostgreSQL.
Не вычисляет состояние задания. Несколько копий оркестратора и воркеров можно
запускать на разных хостах.

## Наблюдение

Измеряет задержку доставки, число попыток, коды ответов, глубину очереди и возраст
самого старого события.
