# Оркестратор группы генерации изображения

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Управляет одной попыткой создания изображения: выбирает свободный воркер
генерации, следит за сроком выполнения и возвращает главному оркестратору ссылку
на созданный кандидат или безопасную ошибку.

## Владение и развёртывание

Хранит локальные попытки генерации, аренды, повторы и сведения об использованной
модели в своей PostgreSQL. Не принимает решение о качестве изображения. Копии
оркестратора работают на обычных хостах, а воркеры — на отдельных GPU-хостах.

## Наблюдение

Измеряет ожидание GPU, время модели, нехватку памяти, число активных попыток,
глубину очереди и загрузку каждого вида оборудования.
