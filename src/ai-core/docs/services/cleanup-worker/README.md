# Микросервис очистки временных данных

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Этот микросервис удаляет только временные объекты AI Core после завершения, ошибки,
отмены или истечения срока хранения. Альбомы и постоянные результаты принадлежат
основному серверу и не входят в область этой службы.

## Входы и выходы

- Читает `ai.worker.temporary.cleanup.commands`.
- Получает точный список временных ключей и причину очистки.
- Возвращает количество удалённых, отсутствующих и не удалённых объектов в
  `ai.worker.temporary.cleanup.results`.

## Владение данными

Не имеет доступа к базам оркестраторов и получает команды только от оркестратора
своей группы. Право удаления ограничено временной областью
AI Core; список произвольных объектов хранилища недоступен.

## Развёртывание и масштабирование

Несколько копий можно запускать на разных хостах. Они безопасно обрабатывают
повторные команды: отсутствие уже удалённого объекта считается успехом.

## Сбои и безопасность

- Временные ошибки удаления повторяются.
- После превышения лимита групповой оркестратор сохраняет проблему и возвращает
  окончательную ошибку главному оркестратору.
- Ключи объектов не содержат идентификатор пользователя.

## Наблюдение

Измеряются задержка очистки, число объектов, объём освобождённого места, ошибки и
возраст самого старого временного объекта.
