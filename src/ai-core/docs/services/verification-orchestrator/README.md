# Оркестратор группы проверки результата

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Запускает обязательные проверки кандидата, собирает ответ воркера и возвращает
главному оркестратору единое решение: принять, отклонить или считать проверку
неопределённой.

## Владение и развёртывание

Хранит локальные попытки проверки и версии правил в своей PostgreSQL. Не меняет
изображение и не запускает повторную генерацию. Оркестратор и воркеры проверки
масштабируются независимо от группы генерации.

## Наблюдение

Измеряет доли решений, причины отклонения, время каждой проверки, ошибки моделей,
глубину очереди и версии правил.
