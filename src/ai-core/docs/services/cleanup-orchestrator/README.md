# Оркестратор группы очистки

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Принимает список временных объектов, делит большую очистку на безопасные части,
повторяет временные ошибки и возвращает сводный итог главному оркестратору.

## Владение и развёртывание

Хранит состояние очистки и список частей в своей PostgreSQL. Не имеет права
удалять постоянные файлы. Несколько копий службы и воркеров можно запускать на
разных хостах.

## Наблюдение

Измеряет возраст очистки, число и объём объектов, повторы, окончательные ошибки и
размер очереди.
