# Микросервис доставки уведомлений

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Этот микросервис отправляет основному серверу подписанные уведомления о смене состояния.
Он не вычисляет состояние, а доставляет событие, созданное главным оркестратором.

## Входы и выходы

- Читает `ai.worker.status.notify.commands`.
- Получает сохранённое событие с `event_id`, `job_id`, `sequence` и состоянием.
- Отправляет запрос на доверенный адрес и возвращает результат доставки в
  `ai.worker.status.notify.results`.

## Владение данными

Не хранит состояние задания и не читает PostgreSQL. Команды получает только от
оркестратора своей группы. Секрет подписи получает из защищённых настроек
окружения.

## Развёртывание и масштабирование

Несколько копий можно запускать на разных хостах. Повторная доставка безопасна:
основной сервер удаляет дубликаты по `event_id` и применяет только возрастающий
`sequence`.

## Сбои и безопасность

- Коды `2xx` подтверждают доставку.
- Ограничение времени, сетевые ошибки и временные коды ответа повторяются.
- Окончательный отказ возвращается групповому, а затем главному оркестратору и
  попадает в наблюдение.
- Адрес назначения не приходит от пользователя; подпись и секрет не журналируются.

## Наблюдение

Измеряются задержка доставки, число попыток, коды ответа, размер очереди и возраст
самого старого не доставленного события.
