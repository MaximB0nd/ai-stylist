# Договор воркера уведомлений

## Очереди

- команды: `ai.worker.status.notify.commands`;
- результаты: `ai.worker.status.notify.results`.

Сообщение использует [общую оболочку](../../message-contracts.md).

## Полезная нагрузка команды

```json
{
  "event": {
    "event_id": "4964143c-b10a-4d89-80b5-5cf9d488d8e2",
    "job_id": "c84dfb50-f331-4c12-88f5-3c1a3e6015aa",
    "sequence": 5,
    "status": "GENERATING",
    "occurred_at": "2026-09-26T19:30:00Z"
  }
}
```

Адрес и секрет подписи берутся только из настроек службы и отсутствуют в
сообщении.

## Полезная нагрузка результата

```json
{
  "status": "DELIVERED",
  "event_id": "4964143c-b10a-4d89-80b5-5cf9d488d8e2",
  "response_code": 204,
  "delivered_at": "2026-09-26T19:30:01Z"
}
```

Любой ответ `2xx` означает доставку. Ограничение времени, ошибка сети, `429` и
`5xx` считаются временными. Остальные `4xx` считаются окончательными. Повторная
доставка того же `event_id` допустима; основной сервер удаляет дубликаты.
