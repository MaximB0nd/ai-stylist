# Оркестратор группы подготовки фотографий

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Принимает от главного оркестратора запуск этапа подготовки, создаёт попытку,
передаёт её свободному воркеру подготовки и возвращает один итог этапа.

## Владение и развёртывание

Хранит только локальные запуски подготовки, повторы и обработанные сообщения в
своей PostgreSQL. Не меняет общее состояние задания. Несколько копий службы можно
запускать на разных хостах; согласование выполняется через локальную базу группы.

## Наблюдение

Измеряет время загрузки и нормализации, число попыток, ошибки исходников, глубину
очереди воркеров и возраст самой старой команды.
