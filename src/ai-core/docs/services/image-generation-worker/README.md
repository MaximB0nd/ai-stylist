# Микросервис генерации изображения

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Этот микросервис создаёт одно изображение-кандидат по исходным фотографиям и
зарезервированному `OutfitSpec`.

## Входы и выходы

- Читает `ai.worker.image.generate.commands`.
- Получает временные ссылки на исходники, `OutfitSpec`, версии модели и инструкции,
  `seed`, номер результата и попытки.
- Записывает кандидат по временной ссылке и возвращает ключ объекта, контрольную
  сумму, размеры и сведения о модели в `ai.worker.image.generate.results`.

## Владение данными

Не хранит состояние задания, не выбирает следующий этап и не обращается к
PostgreSQL. Команды получает только от оркестратора своей группы. Локально хранит
только веса модели и очищаемые рабочие файлы.

## Развёртывание и масштабирование

Это основной потребитель GPU. Каждая копия разворачивается как отдельный
микросервис на одном GPU или на неделимой группе GPU. RabbitMQ распределяет задания
между свободными копиями на разных хостах.

## Сбои и безопасность

- Путь временного результата определяется сообщением и не меняется при его повторе.
- Нехватка памяти, временная недоступность модели и сети возвращаются как временные
  ошибки; новую модельную попытку назначает главный оркестратор.
- Микросервис получает доступ только к объектам своего задания.

## Наблюдение

Измеряются время генерации, ожидание модели, GPU и видеопамять, число ошибок,
размер результата, версия модели, версия инструкции и `seed`.
