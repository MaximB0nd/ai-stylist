# Микросервис AI-стилиста

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Этот микросервис создаёт несколько кандидатов `OutfitSpec` по профилю, пожеланиям и
списку уже занятых признаков. Он проверяет структуру и возвращает кандидатов, но
не резервирует их: атомарное резервирование выполняет главный оркестратор.

## Входы и выходы

- Читает `ai.worker.outfit.style.commands`.
- Получает профиль, ограничения, версию таксономии и признаки запрещённых повторов.
- Возвращает проверенные кандидаты `OutfitSpec` в `ai.worker.outfit.style.results`.

## Владение данными

Не хранит состояние задания и не обращается к PostgreSQL. Команды получает только
от оркестратора своей группы. Локально допускаются
только веса модели и краткоживущий кэш, не содержащий пользовательские данные.

## Развёртывание и масштабирование

Несколько одинаковых копий запускаются на разных хостах или группах GPU. Одна
копия обрабатывает ограниченное число запросов, заданное по доступной памяти.

## Сбои и безопасность

- Повтор команды с теми же версиями и `seed` должен быть воспроизводим настолько,
  насколько это позволяет среда выполнения.
- Нарушение схемы или таксономии возвращается как отклонённый результат.
- Пользовательский текст считается недоверенным и не может менять системные
  правила или формат ответа.

## Наблюдение

Измеряются задержка, число кандидатов, ошибки схемы, причины отклонения, расход
памяти, версия модели и версия инструкции.
