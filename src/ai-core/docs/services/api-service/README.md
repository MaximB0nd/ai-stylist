# Служба API

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Служба API является единственной внешней точкой входа AI Core. Она проверяет
служебный токен, формат запроса и ограничения размера, затем передаёт команду
главному оркестратору через его закрытый внутренний интерфейс.

## Входы и выходы

- Принимает операции создания, чтения и отмены задания из
  [внешнего договора](../../ai-core-contract.md).
- Возвращает только сохранённое главным оркестратором состояние.
- Не публикует этапы обработки самостоятельно.

## Владение данными

Служба не имеет собственной предметной базы и не хранит задания в памяти между
запросами. Она не читает PostgreSQL главного оркестратора напрямую.

## Развёртывание и масштабирование

Служба не хранит состояние, поэтому несколько копий можно запускать на разных
хостах за балансировщиком. Все копии используют одинаковую версию внешнего
договора и одинаковые ограничения запросов.

## Сбои

- При недоступном главном оркестраторе возвращается временная ошибка.
- Повтор создания безопасен благодаря `Idempotency-Key`.
- Ограничение времени запроса не отменяет уже сохранённое главным оркестратором задание.

## Безопасность и наблюдение

- Проверяет служебный токен и ограничивает частоту запросов.
- Не записывает фотографии, временные ссылки и токены в журналы.
- Измеряет число запросов, задержку, коды ответов, отказы проверки и доступность
  главного оркестратора.
