# Договор службы API

## Граница договора

Служба принимает запросы только от основного сервера. Полный внешний формат
описан в [общем договоре AI Core](../../ai-core-contract.md); этот файл закрепляет,
какую часть выполняет служба API.

## Операции

| Метод | Путь | Назначение |
| --- | --- | --- |
| `POST` | `/v1/jobs` | Создать или вернуть ранее созданное задание |
| `GET` | `/v1/jobs/{job_id}` | Получить сохранённое состояние |
| `POST` | `/v1/jobs/{job_id}/cancel` | Запросить отмену |

Для создания обязательны заголовки `Authorization` и `Idempotency-Key`. Служба
проверяет тело, диапазон `requested_image_count` и срок временных ссылок, затем
вызывает внутреннюю операцию главного оркестратора. Идентификатор основного сервера в тело
запроса и ответа не добавляется.

## Ошибки

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Запрос не прошёл проверку",
    "retryable": false
  }
}
```

Служба возвращает `4xx` для неверного или запрещённого запроса, `503` при
временной недоступности главного оркестратора и не раскрывает внутренние сообщения об
ошибках. Повтор `POST /v1/jobs` с тем же ключом безопасен.
