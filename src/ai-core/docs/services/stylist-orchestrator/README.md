# Оркестратор группы AI-стилиста

Договор службы: [CONTRACT.md](CONTRACT.md).

## Назначение

Принимает запрос на подбор комплектов, управляет попытками модели и возвращает
главному оркестратору проверенный список кандидатов `OutfitSpec`.

## Владение и развёртывание

Хранит только локальные попытки стилиста и технические ошибки в своей PostgreSQL.
Резервирование выбранного комплекта остаётся у главного оркестратора. Копии
группового оркестратора и воркеров масштабируются отдельно.

## Наблюдение

Измеряет время подбора, число кандидатов, ошибки схемы, повторы модели, глубину
очереди и версии модели и инструкции.
