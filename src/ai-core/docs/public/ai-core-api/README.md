# Внешний интерфейс AI Core

## Для чего создан

Единая точка входа основного сервера в AI Core. Скрывает внутренние службы и
очереди за стабильным HTTP-интерфейсом.

## Функции

- проверяет служебный токен;
- проверяет HTTP-запрос и обязательные поля;
- принимает создание, чтение состояния, отмену и подтверждение получения результатов;
- передаёт допустимый запрос главному оркестратору;
- преобразует внутренний ответ в формат внешнего договора;
- возвращает безопасные ошибки без внутренних данных;
- сообщает поддерживаемые ограничения через `GET /v1/capabilities`.

## Не выполняет

- не хранит состояние заданий;
- не управляет этапами и повторами;
- не передаёт байты изображений;
- не обращается к PostgreSQL, RabbitMQ и временному S3.
