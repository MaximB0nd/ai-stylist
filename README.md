# AI Stylist

Проект для разработки AI-стилиста.

## Структура проекта

- `src/frontend` — клиентская часть приложения.
- `src/backend_core` — серверная часть приложения.
- `src/ai-core` — независимо развёртываемый backend для AI-задач.
- `docs` — документация и важные проектные решения.

## Подключение AI Core

[Руководство интегратора](src/ai-core/README.md): подключение к любому backend,
HTTP-контракт, статусы, ошибки, скачивание и подтверждение результатов.
