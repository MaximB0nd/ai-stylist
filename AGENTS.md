# Инструкции для AI-агентов

- Соблюдайте существующую структуру проекта.
- Не смешивайте код клиентской и серверной частей: используйте `src/frontend` и `src/backend` соответственно.
- Документируйте важные архитектурные и технические решения в `docs`.
- Не изменяйте файлы, не связанные с текущей задачей.
